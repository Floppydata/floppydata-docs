This reference is generated from the official OpenAPI schema and documents the current `/v2` Client API. Legacy `/v1` endpoints are still listed in the Legacy v1 section for existing integrations.

## Base URL

```text
https://api.floppydata.net
```

## Authentication

All requests require:

```http
X-Api-Key: YOUR_API_KEY
```

You can manage API keys in [account settings](https://app.floppydata.com/settings/account).

## Endpoint Coverage

- Web Data fetch, balance, and usage
- Rotating proxy connection, locations, balance, and usage
- Static proxy inventory
- Proxy check tool
- Account balance and usage rollups
