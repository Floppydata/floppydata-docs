## Authentication

```http

```

## Groups

- **Web Data**: fetch a page, check Web Data balance, check Web Data usage
- **Rotating Proxy**: build a connection, list locations, check balance, check usage
- **Static Proxy**: list assigned static proxies
- **Proxy Tools**: check a proxy connection
- **Account**: account-level balances and usage rollups
