---
title: 'Create a Session'
openapi: '/api-reference/openapi.json POST /v2/browser/sessions'
---

<Note>
  The smallest request is `{}` and creates burner browser state. The response includes a signed `connectUrl`, an opaque `settings.id`, and persistence metadata; add `persist.ttlSeconds` when you need `settings.id` to remain reusable after the session ends. The API does not accept `startUrl`.
</Note>
