## Standard Request Template

```bash
curl --request GET \
  --url "$FLOPPY_BASE_URL/v2/proxy/rotating/usage?proxyType=residential" \
  --header "X-Api-Key: $FLOPPY_API_KEY"
```

## Useful Tooling

- `curl` for API calls
- `jq` for formatting JSON responses
- your HTTP client of choice (Postman, Insomnia, Bruno)

Example with `jq`:

```bash
curl --silent \
  --url "$FLOPPY_BASE_URL/v2/proxy/static" \
  --header "X-Api-Key: $FLOPPY_API_KEY" | jq
```

## Handling Responses

- Most endpoints return `200` on success.
- `POST /v2/proxy/check` may return `400` when the proxy connection cannot be validated.
- Usage endpoints return UTC rollups for `yesterday`, `last7Days`, and `last30Days`. If you pass `from` or `to`, the response also includes `requestedRange`.
