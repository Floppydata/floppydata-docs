---
title: "Check Proxy Guide"
description: "Validate proxy connectivity and location details."
---

## Endpoint

- `POST /v2/proxy/check`

## Send Connection String

```bash
curl --request POST \
  --url "$FLOPPY_BASE_URL/v2/proxy/check" \
  --header "Content-Type: application/json" \
  --header "X-Api-Key: $FLOPPY_API_KEY" \
  --data '{
    "connectionString": "http://username:password@geo.g-w.info:10080"
  }'
```

## Success Response

```json
{
  "ip": "123.45.67.89",
  "location": {
    "countryCode": "US",
    "country": "United States",
    "state": "California",
    "city": "San Francisco"
  }
}
```

Use the `connection.connectionString` value returned by rotating or static proxy endpoints when you want to validate a FloppyData proxy.
