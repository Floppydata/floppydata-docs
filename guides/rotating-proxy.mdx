---
title: "Rotating Proxy Guide"
description: "Build rotating proxy connections, choose locations, and track traffic."
---

## Endpoints

- `POST /v2/proxy/rotating/connections`
- `GET /v2/proxy/rotating/locations`
- `GET /v2/proxy/rotating/balance`
- `GET /v2/proxy/rotating/usage`

## 1. Build a Connection

```bash
curl --request POST \
  --url "$FLOPPY_BASE_URL/v2/proxy/rotating/connections" \
  --header "Content-Type: application/json" \
  --header "X-Api-Key: $FLOPPY_API_KEY" \
  --data '{
    "type": "residential",
    "country": "US",
    "city": "New York",
    "protocol": "http",
    "rotation": 15
  }'
```

Use `connection.connectionString` from the response as the copy-paste proxy URL.

```json
{
  "connection": {
    "protocol": "http",
    "host": "geo.g-w.info",
    "port": 10080,
    "username": "user-USERNAME-type-residential-session-my_session-country-US-city-New_York-rotation-15",
    "password": "PASSWORD",
    "connectionString": "http://user-USERNAME-type-residential-session-my_session-country-US-city-New_York-rotation-15:PASSWORD@geo.g-w.info:10080"
  }
}
```

Supported request fields include `type`, `country`, `state`, `city`, `asn`, `rotation`, `session`, and `protocol`.

- `type` must be `residential`, `mobile`, or `datacenter`.
- `rotation=-1` requests a new IP every request.
- `rotation=0` keeps the same IP within a session.
- `rotation=1..60` rotates after that many minutes.
- If `state` is supplied, it takes precedence over `city`; otherwise `city` is used.

## 2. List Available Locations

```bash
curl --request GET \
  --url "$FLOPPY_BASE_URL/v2/proxy/rotating/locations?type=residential" \
  --header "X-Api-Key: $FLOPPY_API_KEY"
```

Location data is a static country-level list of available `cities` and `states`. It is not a city-under-state mapping.

## 3. Check Traffic Balance

```bash
curl --request GET \
  --url "$FLOPPY_BASE_URL/v2/proxy/rotating/balance" \
  --header "X-Api-Key: $FLOPPY_API_KEY"
```

Response includes `expiring`, `nonExpiring`, and `total` traffic buckets.

## 4. Query Usage

```bash
curl --request GET \
  --url "$FLOPPY_BASE_URL/v2/proxy/rotating/usage?from=2026-03-01&to=2026-03-12&proxyType=residential&countryCode=US" \
  --header "X-Api-Key: $FLOPPY_API_KEY"
```

You can filter by `from`, `to`, `poolId`, `proxyType`, and `countryCode`.
Usage responses include `yesterday`, `last7Days`, `last30Days`, `lastUpdatedAt`, and `requestedRange` when you pass a date range.
