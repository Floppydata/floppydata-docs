title: "Static IP Guide"
description: "Retrieve static proxy inventory, pending IP count, and connection strings."
---

## Endpoint

- `GET /v2/proxy/static`

## List Static IPs

```bash
curl --request GET \
  --url "$FLOPPY_BASE_URL/v2/proxy/static" \
  --header "X-Api-Key: $FLOPPY_API_KEY"
```

## Response Shape

- `items`: array of static proxy records
- `pendingCount`: number of static IPs still pending allocation

Each `items` entry contains fields like:

- `connection.host`, `connection.port`, `connection.username`, `connection.password`
- `connection.connectionString`, the copy-paste proxy URL
- `ip`, `countryCode`, `countryName`
- `proxyType` from your static IP inventory

<Note>
  Static proxy `proxyType` values describe already allocated static inventory. They are separate from rotating proxy types, which are `residential`, `mobile`, and `datacenter`.
</Note>

## Extract First Connection Values

```bash
curl --silent \
  --url "$FLOPPY_BASE_URL/v2/proxy/static" \
  --header "X-Api-Key: $FLOPPY_API_KEY" | jq '.items[0].connection.connectionString'
```
