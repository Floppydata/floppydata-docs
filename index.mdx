## Overview

The Floppydata Client API lets you work with:

- Rotating proxy traffic and locations
- Static proxy inventory
- Web Data requests
- Proxy validation tools
- Account balance and usage rollups

Base URL: `https://api.floppydata.net`

## Quick Request

```bash
curl --request GET \
  --url 'https://api.floppydata.net/v2/proxy/rotating/balance' \
  --header 'X-Api-Key: YOUR_API_KEY'
```

<Note>
  Use the `X-Api-Key` header for all requests.
</Note>
