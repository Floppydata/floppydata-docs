The Floppydata Client API helps you do four jobs:

<CardGroup cols={2}>
  <Card title="Fetch Web Data" icon="file-code" href="/guides/web-data">
    Send a URL and receive fetched HTML with optional country, city, difficulty, and cache controls.
  </Card>

  <Card title="Build a proxy connection" icon="plug" href="/guides/rotating-proxy">
    Generate a copy-paste rotating proxy URL from dashboard-style location and rotation options.
  </Card>

  <Card title="Check usage and balances" icon="chart-line" href="/guides/balances-usage">
    Read Web Data request balance, rotating traffic balance, and UTC usage rollups.
  </Card>

  <Card title="List static proxies" icon="server" href="/guides/static-ips">
    Retrieve your static proxy inventory with host, port, credentials, and connection strings.
  </Card>
</CardGroup>

## Base URL

```text
https://api.floppydata.net
```

All API requests use the `X-Api-Key` header.

```bash
curl --request GET \
  --url "https://api.floppydata.net/v2/account/balances" \
  --header "X-Api-Key: YOUR_API_KEY"
```
