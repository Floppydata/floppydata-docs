Use the sandbox to send real Client API v2 requests without leaving the docs. Open an endpoint, paste your API key into `X-Api-Key`, review the prefilled request, then run it from the playground.

<Warning>
  Sandbox requests run against production and can consume account balance or proxy traffic.
</Warning>

## How to Run a Request

1. Choose one sandbox card above.
2. Enter your Client API key in the `X-Api-Key` field.
3. Keep the example values or edit the request body/query fields.
4. Click the playground send button and inspect the live response.

<Note>
  Use example values first. For proxy checks, use a `connection.connectionString` returned by rotating connections or static proxies.
</Note>
