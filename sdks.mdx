The official SDKs wrap every Client API v2 endpoint with typed parameters and responses, read your key from `FLOPPYDATA_API_KEY`, and raise typed errors. They are generated from the same OpenAPI spec as the [API Reference](/api-reference/introduction), and new SDK versions are released when the API changes.

## Make a First Call

Create or copy a Client API key from [API keys](https://app.floppydata.com/api-keys) and set it as `FLOPPYDATA_API_KEY`:

```bash
export FLOPPYDATA_API_KEY="YOUR_API_KEY"
```

<CodeGroup>

```ts TypeScript
import { FloppyData } from '@floppydata/sdk';

const fd = new FloppyData(); // reads FLOPPYDATA_API_KEY

const { data: balances } = await fd.getAccountBalances();
console.log(balances.webData?.requests.remaining);

const { data: page } = await fd.fetchWebData({ url: 'https://example.com', difficulty: 'auto' });
console.log(page.html.length);
```

```python Python
from floppydata import FloppyData

fd = FloppyData()  # reads FLOPPYDATA_API_KEY

balances = fd.account.get_account_balances()
print(balances.web_data.requests.remaining)

page = fd.web_data.fetch_web_data(url="https://example.com", difficulty="auto")
print(len(page.html))
```

</CodeGroup>

<Warning>
  Keep the API key on your server. Anyone holding it can spend your balance.
</Warning>
